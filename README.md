## Featured Work

### Sunnysir.com / SMW

A production academic management platform for a math education center in Bangladesh.

**Tech:** Django, Django REST Framework, PostgreSQL, Redis, Celery, Next.js, Nginx, Gunicorn, Cloudflare

Highlights:

- Admissions, student records, secure payments, academic communication, and admin workflows
- Payment validation, student provisioning, fee tracking, exam/result workflows, and dashboards
- Production deployment with Nginx, Gunicorn, PostgreSQL, Redis/Celery, GitHub Actions, Cloudflare, and server monitoring

### Donation Management System

Backend platform built during my internship for managing donations, users, transactions, payment methods, recurring donations, and admin workflows.

**Tech:** Django, Django REST Framework, PostgreSQL, JWT, RBAC, GitHub Actions

Highlights:

- Designed UML/ER structure and implemented database models with Django ORM
- Developed and tested 29+ RESTful API endpoints
- Implemented JWT authentication, role-based access control, recurring donation logic, search, filtering, pagination, and CI/CD deployment workflow

### DIU Counseling Management System

Role-based counseling slot booking and scheduling platform for students and faculty.

**Tech:** Python, Django, PostgreSQL, HTML, CSS, JavaScript

Highlights:

- Real-time slot booking and secure counseling workflow management
- Automated email notifications for slot requests and approvals
- Designed backend models, session workflows, CRUD operations, and authentication logic
